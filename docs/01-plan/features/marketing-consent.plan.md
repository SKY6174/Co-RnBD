# 홍보 메일 수신 동의와 발송 — Plan

2026-11-17. [메일링 운영 계획](mailing-operations.plan.md) 3.2절·4절 7번 항목.
결정(사용자): 동의는 마이페이지와 참가 신청에서 받고, 발송은 기존 outbox 경로를 재사용하며, 동의와 발송을 한 PR로 한다.

- 로그인한 회원만 선택 동의한다(기본 해제). 기존 회원·투고자·심사위원 명단을 동의 없이 홍보 대상으로 쓰지 않는다.
- 동의·철회 이력(일시, 경로)을 남겨 동의 사실을 증명할 수 있게 한다.
- 동의·철회·수신거부 처리 결과를 메일로 알린다(정보통신망법 시행령: 처리 후 14일 이내 전송자·일시·결과 통지).
- 위원장 운영 공지에 "홍보 수신 동의자" 대상을 추가한다. 이 대상은 제목 앞 `(광고)`, 본문 끝 전송자·연락처·
  수신거부 링크와 동의 일자를 넣고, `List-Unsubscribe`(한 번 클릭) 헤더를 붙인다.
- 21:00–08:00 KST에는 보내지 않는다. 확정 시점에 08:00–21:00 안에 끝나지 않을 발송은 거부하고, 서버도 야간 요청을 거절한다.
- 동의 후 2년이 지난 회원은 재확인 전까지 홍보 대상에서 뺀다. (2년마다 동의 여부 통지 발송은 2028년 전 별도 작업.)
- 수신거부 링크는 확인 화면의 버튼으로 철회한다(링크 미리보기 자동 철회 방지). 메일 클라이언트의 한 번 클릭 요청은 바로 처리한다.
- 개인정보처리방침에 선택 동의 항목·목적·보유기간과 Resend 위탁 목적을 추가한다.
