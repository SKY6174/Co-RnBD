# 공동위원장 현황 모니터링 — 계획

- 송경영의 확인된 두 Auth 계정에 위원장 역할과 `is_super_admin` 표식을 부여한다.
- 슈퍼 관리자는 기존 위원장 권한을 포함한다. 권한은 DB에서만 부여하며 이메일 문자열이나 화면 표시로 권한을 판단하지 않는다.
- 현재 학회의 일반 참가신청과 논문 투고 현황을 한 화면에서 확인한다. 합계, 상태별 건수, 검색, 상태 필터, 새로고침, 기존 운영 화면 이동을 제공한다.
- 원고 초안과 취소된 참가신청은 접수·확정 건수와 구분한다. 이 화면은 읽기 전용으로 두고 실제 상태 변경은 기존 운영 화면에서 수행한다.
- 변경 파일: `staff_roles` 마이그레이션, 모니터링 페이지와 브라우저 코드, 경로·메뉴, 운영 안내. 개인정보는 기존 RLS를 통해서만 읽는다.
- 검증: SQL 역할 및 정책 확인, JS 문법·TypeScript·빌드, 화면 접근 및 좁은 화면 확인. 운영 DB 적용과 사이트 배포는 별도 상태로 기록한다.
