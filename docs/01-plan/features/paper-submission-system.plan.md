# 논문 투고·심사 시스템 기획

## 목적
기존 Co-R&BD 2026 안내 사이트에 전문대학 규모의 원고 투고·심사 기능을 연결한다. CMT의 저자 접수, 심사 배정, 심사 입력, 위원장 판정 흐름만 채택한다.

## 범위
- 이메일·비밀번호 회원가입/로그인/재설정, Google 및 Naver 로그인, 저자 프로필
- 원고 초안/제출/수정, 공동저자·소속, PDF 파일 버전과 접수번호
- 위원장 배정(원고당 권장 2명), 심사위원의 간단한 권고·의견, 위원장 판정
- 저자·심사위원·위원장 대시보드, 모바일 대응
- Supabase Postgres/Auth/비공개 Storage 및 RLS, Vercel 정적 사이트의 설정 엔드포인트

## 범위 밖
참가등록·결제, 자동 이메일, 블라인드 심사, 세부 점수표, 메타심사, 공개 자료집. 논문 일정과 주최 표기는 기존 CFP 가안을 유지한다.

## 완료 조건
- 저자가 로그인해 PDF를 제출하고 자신의 상태를 확인한다.
- 심사위원은 배정된 원고만 열람하고 심사한다.
- 위원장은 배정과 최종 판정을 기록한다.
- RLS가 타인의 원고·파일·심사를 차단한다.
- 모바일 너비에서 주요 흐름이 사용 가능하며 GitHub main에 push한다.

## 외부 설정
Google/Naver OAuth 앱의 Client ID/Secret 및 콜백 등록은 각 서비스 관리자 설정이 필요하다. 운영 개시일·마감·개인정보 보존 기준은 주최 측 확정 후 설정한다.
