# 세션 좌장 운영 — 기획

## 근거와 적용 범위

2026 KICS 추계종합학술발표회는 좌장에게 세션 시작 전 발표자 참석 확인, 구두발표 시간과 질의응답 진행, 포스터 토론 유도, 종료 후 우수논문 후보 추천을 맡긴다. 논문 제출과 참가 등록은 분리하고 제출 체크리스트 및 수정 안내를 제공한다. 참고: [논문·좌장 안내](https://conf.kics.or.kr/2026f/journalRegister), [수정 안내](https://conf.kics.or.kr/sites/2026f/board/article/5364), [등록 안내](https://conf.kics.or.kr/2026f/enroll).

Co-R&BD는 이미 투고·참가 신청과 프로그램 편집이 분리되어 있다. 2026 행사의 발표 형식과 시상 기준이 아직 확정되지 않았으므로 KICS의 마감, 등록비, 저작권 양도, 추천 편수는 가져오지 않는다.

## 목표

1. 위원장이 가입된 계정을 구두·포스터 세션의 좌장으로 배정하거나 해제한다.
2. 위원장이 채택된 논문을 형식이 맞는 세션에 배정하고 실제 발표자를 기록한다.
3. 좌장이 자기 세션의 발표 목록만 열람하고 발표 여부, 진행 메모, 우수발표 후보 추천 또는 미추천을 제출한다.
4. 위원장이 제출 상태와 결과를 확인하되, 좌장에게 심사·판정·PDF·참가자 명단 권한을 주지 않는다.

## 검수

- DB 정책으로 비좌장 및 타 세션 좌장의 읽기·쓰기 거부를 확인한다.
- 좌장이 세션 배정·발표자 수정·타인의 기록 수정·심사 판정을 할 수 없음을 확인한다.
- 발표 확인이 빠진 상태에서는 보고서를 완료할 수 없고, 완료 후 기록을 수정할 수 없다.
- 공개 프로그램은 기존 공개 승인된 정보만 표시한다. 개인정보와 추천 결과는 비공개로 유지한다.
