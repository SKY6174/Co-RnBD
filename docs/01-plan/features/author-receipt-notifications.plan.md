# 투고자 접수 확인 이메일 — Plan

신규 투고와 수정본 재제출의 정상 저장 완료를 투고 계정의 인증 이메일로 각각 확인한다.
기존 편집 담당자 알림·비공개 outbox·재시도·중복 방지·Resend 연결을 유지한다.

- 인증된 papers.owner_id 계정만 수신한다. 임의 연락 이메일·공동저자 전체를 대신 사용하지 않는다.
- 신규/수정본 확인을 구분하고 원고 제목·접수번호·해당 제출 시각·내 원고 링크를 안내한다.
- 초안·실패·동일 제출본 replay는 추가 발송하지 않는다. 제출 후 재제출되어도 과거 정상 접수 사실을 확인할 수 있다.
- 수신 이메일/소유권/원본 제출 이벤트를 dispatch 직전에 재검증하고 기록을 보호한다.
- 새 flag 비활성 migration → v4 서버 배포 → 활성화. 격리 생명주기 및 실제 지정 계정의 두 양식 전달 확인 후 보고한다.
