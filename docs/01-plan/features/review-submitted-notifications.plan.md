# 심사의견 제출 알림 — Plan

심사위원의 제출 완료를 담당 분야 AE와 운영자가 지정한 심사위원장 계정에 이메일로 알린다.
기존 배정·판정 메일과 동일한 private outbox/pg_net/cron/Resend를 재사용한다.

- 실제 최초 제출 또는 제출된 의견·추천의 변경만 알림을 생성한다. 임시저장·동일 내용 재저장은 제외한다.
- 활성 분야 AE와 지정된 chair 권한 계정의 인증 이메일을 사용한다. AE의 저자/공동저자/이해관계 거절 제외를 유지한다.
- 겸임 계정은 한 이벤트당 한 통만 받는다. 심사 본문·추천·심사위원 신원·PDF는 이메일에 넣지 않는다.
- 발송 직전에 원고/심사 상태 및 수신 권한을 재검증한다. 재시도와 기존 메일 호환성을 보존한다.
- 새 알림은 별도 비활성 flag로 migration → 서버 배포 → 지정 수신자 설정 → 활성화한다.
- 격리 브라우저 생명주기 및 DB allow/deny/롤백/재시도 검증 후 PR·병합·운영 배포와 지정 계정 테스트를 수행한다.
