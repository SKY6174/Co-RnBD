# 세션 좌장 모집·선정 — 기획안

## 배경

[KICS 2026 추계학술발표회 좌장 안내](https://conf.kics.or.kr/2026f/journalRegister)는 좌장 지원 자격, 현장 참여, 전공 분야 검토, 선정 결과 안내와 업무를 한곳에 제시한다. 우리 사이트에는 좌장의 세션별 업무·권한 부여 기능이 배포됐지만, 지원 의사 확인과 후보 검토 절차는 없다. 현재 운영 DB에 구두·포스터 세션과 채택 원고가 없어 실배정도 아직 없다.

KICS의 교수·정보통신 전문가 자격, 학회 등록 의무, 신청 마감, 추천 편수는 Co-R&BD의 확정 정책이 아니다. 우리 행사에 그대로 게시하거나 자동 적용하지 않는다.

## 목표

1. 지원자의 자발적 의사와 행사일 현장 참여 가능 여부를 수집하고, 기존 계정의 이름·소속·전문 분야를 재사용한다.
2. 위원장이 지원자의 적합성과 이해관계를 검토해 선정 여부를 기록한다. 선정만으로 원고·심사·세션 데이터 접근 권한은 생기지 않는다.
3. 승인된 지원자를 확정된 구두·포스터 세션에 배정할 때만 기존 `session_chairs` 권한이 생긴다.
4. 지원자에게 본인 접수·선정·배정 상태를 보여 주되 후보 명단과 위원장 검토 메모는 공개하지 않는다.

## 범위와 선행 결정

기존 `conference_settings`의 회차별 운영 방식과 `profiles`의 전문 분야를 재사용하는 단일 학회 흐름을 설계한다. 공개 모집의 자격·기간·선정 기준·참가 등록 조건은 운영 주체가 확정해야 한다. 그전에는 모집을 열거나 가상의 좌장·세션을 만들지 않는다. 자동 이메일과 별도 외부 심사·시상 시스템은 범위에 넣지 않는다.

## 검수 기준

- 지원자 본인과 위원장만 지원서를 읽고, 위원장만 선정 상태를 바꾼다.
- 일반 회원·미선정 지원자에게 `session_chairs`의 접근 권한이 생기지 않는다.
- 저자 본인의 원고가 배정된 세션을 맡지 못하는 기존 DB 차단과 위원장의 기관·과제 이해관계 확인을 유지한다.
- 지원 취소·회차 전환·배정 교체 시 상태가 모순되지 않고 개인정보 보존 정책과 일치한다.
