# DB 연결·화면 응답 최적화 계획

- 운영 사이트의 공개 설정, 회차, 참가 설정, Auth 설정을 읽기 전용으로 확인한다.
- 익명 요청이 비공개 회원·원고·심사·참가 자료를 읽을 수 없는지 확인한다.
- 참가 신청과 투고 화면의 독립적인 조회를 병렬로 실행해 직렬 네트워크 대기를 줄인다.
- 초기 인증 이벤트가 기존 초기 조회와 중복 실행되지 않게 한다.
- 권한 정책, 데이터 모델, 로그인 결과, 오류 표시 방식은 유지한다.
- JavaScript 구문, TypeScript, 빌드, 공개 페이지 및 프리뷰 동작을 검증한다.

운영 DB에 쓰기 시험이나 스키마 변경은 하지 않는다. 로그인 계정이 필요한 구간의 실제 체감 시간은 운영 계정으로 별도 확인한다.
