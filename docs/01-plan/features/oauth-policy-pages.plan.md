# OAuth 공개 정책 페이지 계획

## 목적
Google OAuth 앱 브랜딩에 사용할 공개 개인정보처리방침과 서비스 이용약관을 `co-rnbd.org`에 제공한다.

## 범위
- 독립된 HTML 페이지 `privacy.html`, `terms.html`과 모바일 대응 스타일
- 홈페이지, 모집공고, 투고 화면의 푸터에서 두 페이지로 연결
- 현재 구현된 계정·투고·심사 기능만 설명하고 일반 참가등록은 별도 절차임을 명시
- 실제 배포 후 HTTPS 응답과 주요 링크 확인
