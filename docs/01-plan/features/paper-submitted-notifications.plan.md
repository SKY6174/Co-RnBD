# 신규 투고·수정본 재제출 알림 — Plan

저자의 신규 투고와 수정본 재제출이 정상 저장되면 담당 분야 AE와 지정 심사위원장에게 이메일을 보낸다.
기존 심사의견 제출 알림의 인증 계정·분야·이해관계·수신자 중복 제거 규칙과 발송 큐를 재사용한다.

- 초안, 수정본 임시저장, 실패한 제출, 같은 제출본 이벤트 재생은 알림을 늘리지 않는다.
- 신규/재제출 양식을 구분하며 원고 제목·접수번호·분야와 포털 링크만 안내한다. PDF·초록·저자 목록은 보내지 않는다.
- 같은 트랜잭션의 outbox, 기존 재시도·idempotency·23시간 경계를 유지한다. 발송 직전 제출본·역할을 재검증한다.
- 신규 flag 비활성 migration → 코드 배포 → 지정 위원장 수신자 확인 → 활성화한다.
- 격리된 실제 투고·수정본·심사·판정 생명주기 및 오류/중복/권한 검증, PR·merge·push·deploy, 운영 테스트 메일 전달을 확인한다.
