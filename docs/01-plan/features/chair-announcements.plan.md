# 위원장 승인형 일괄 운영 공지 — Plan

2026-11-17. [메일링 운영 계획](mailing-operations.plan.md) 3.1절·4절 6번 항목.

- 위원장이 운영 페이지에서 제목·본문을 쓰고, 정해진 대상 그룹 하나를 고른 뒤
  **수신자 수 확인 → 본인에게 테스트 발송 → 수신자 수를 다시 입력해 확정**하는 순서로 보낸다.
- 대상 그룹(현재 회차): 참가 확정자, 참가 신청자(확인 대기+확정), 투고자(제출 이후 원고 보유), 채택 원고 투고자,
  초안만 보유한 회원, 활성 심사위원. 자유 주소 입력·CSV 업로드는 없다.
- 수신자는 이메일 인증을 마친 계정만, 계정당 한 통. 수신 거부 주소는 제외한다.
- 기존 outbox·worker·재시도·중복 방지·Reply-To(사무국 office@)·전달 결과 기록을 그대로 쓴다. 새 외부 서비스는 없다.
- 비광고성 운영 안내만 보낸다. 홍보성 내용은 별도 동의 기반 메일(계획 3.2)로 분리한다.
- 확정 후 아직 발송되지 않은 공지는 취소할 수 있다. 이미 발송 서비스가 접수한 메일은 회수할 수 없다.
- worker는 분당 2통을 보내므로 확정 화면에 예상 소요 시간을 보여 준다.
- 개인정보처리방침의 Resend 위탁 목적에 "행사 운영 공지"를 추가한다.
