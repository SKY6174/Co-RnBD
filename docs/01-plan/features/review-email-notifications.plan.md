# 심사 배정·판정 이메일 자동 알림 — Plan

2026-11-07. 기존 분야별 AE 심사 흐름에 자동 이메일을 추가한다.

- 심사위원장 배정 저장 → 배정된 심사위원의 인증된 계정 이메일로 심사 요청.
- AE/위원장 판정 공개 → 투고 계정의 인증된 이메일로 채택·반려·수정 요청. 임의 연락 이메일이나 공동저자 전체에 발송하지 않는다.
- 원고/PDF/심사 의견·권한은 기존 모델을 유지한다. 이메일에는 제목·판정 사유와 포털 안내만 포함하고 PDF·심사위원 신원은 넣지 않는다.
- 기존 Resend 계정을 재사용하고 사용자 요청으로 `co-rnbd.org` 루트 도메인을 추가·인증한다. 심사 알림은 `no-reply@co-rnbd.org`에서 보낸다. 새 유료 Marketplace 리소스는 만들지 않는다.
- 트랜잭션 발송 대기열, 중복 방지, 실패 재시도, 운영자 상태 표시를 구현한다.
- 사용자 승인 범위: 자동 메일 구현, PR/push/merge/deploy. 발송 검증은 지정된 테스트 계정 3개만 사용하고 실제 참가자에게 시험 메일을 보내지 않는다.
- 검증: 격리 로컬의 실제 Auth·DB·Storage·브라우저와 로컬 메일 수집기로 전체 배정/판정/수정 흐름 및 실패·중복·권한 차단을 검사하고, 운영은 롤백 검증과 명시적 테스트 메일로 확인한다.
