# Supabase CLI 3 호환성 계획

2026-11-07 · 기준 커밋 `daa7130`

## 문제와 범위

로컬 Homebrew CLI와 공식 최신 안정판은 3.0.0이다. 저장소에는 CLI 버전 기준이 없고,
설정의 `experimental.orioledb_version`은 CLI 3에서 `db`로 이동했으며
`auth.email.enable_signup`과 `auth.sms.enable_signup`은 폐기 예정이다.
원격 DB 명령은 CLI 3에서 기본적으로 로컬을 가리키고, 원격 변경에는 명시적 확인이 필요하다.

CLI 3.0.0을 단일 파일로 고정하고 로컬·검증 스크립트·CI가 같은 버전을 사용하게 한다.
설정의 의미는 유지하면서 현재 키로 바꾼다. 원격 명령·동의 방식은 운영 문서에 명시한다.
전체 17개 페이지의 데스크톱·모바일, API, 공개 조회와 비공개 데이터 접근 차단을 검증한다.

## 완료 조건

- 공식 최신 안정판과 로컬·저장소·CI 버전이 일치한다.
- CLI 3에서 설정 파싱 경고가 사라지고 실제 원격 읽기 쿼리가 성공한다.
- 17개 페이지와 기존 HTML URL, 클라이언트 자산, API와 로그인 보호 화면을 검증한다.
- 타입 검사·빌드·기존 캐시 검증·차이 검사를 통과한다.
- PR을 생성하고 검사 후 병합한다. 운영 배포의 커밋과 실제 응답을 검증한다.

## 안전성과 복구

DB 마이그레이션·RLS·운영 설정 push·회원 데이터·인증 메일은 변경하지 않는다.
운영 검증은 로그인하지 않는 읽기 전용이다. 코드 문제는 PR revert와 이전 Vercel 배포로 복구한다.
인증 후 투고·결제·증빙 발급 등 쓰기 흐름은 이 읽기 전용 검사와 구분해 보고한다.
