# 운영 지정 계정 심사 생명주기 검증 — Plan

2026-11-08. 사용자가 지정 계정과 실제 운영 화면·이메일의 전체 절차 테스트를 요청했다.
지정된 심사위원장 계정이 저자를 겸하고 기존 두 심사위원 계정은 심사위원/AE 겸임으로 검증한다.

- 운영 테스트 원고 1건만 생성하고 제목·PDF·의견에 시스템 검증용임을 표시한다.
- 신규 투고 → 2인 배정/의견 → 담당 AE 수정 요청 → 새 PDF 재제출 → 새 배정/재심 → 담당 AE 최종 채택.
- 저자의 판정/익명 의견, 위원장의 전체 배정/기록, AE의 담당 분야 범위, 역할별 다음 작업을 확인한다.
- 정상 workflow 메일을 지정 3계정으로 발송하고 outbox/provider 기록을 단계별 대조한다.
- 기존 Auth 비밀번호·역할·프로필·메일 설정·운영 단계는 변경하지 않는다. 기존 관리자 연결로 일회성 로그인만 준비한다.
- 문제가 있으면 격리 환경에서 재현·수정·회귀 → PR/Preview/병합/배포 → 같은 테스트 원고 재확인.
- 정상 이력은 최종 테스트 원고로 보존한다. 다른 원고·참가자나 미지정 수신자에는 쓰기/메일을 보내지 않는다.
