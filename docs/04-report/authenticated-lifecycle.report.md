# 로그인 이후 저장 흐름 작업 보고

2026-11-07 · [검증 상세](../03-analysis/authenticated-lifecycle.analysis.md)

새 로컬 Supabase에서 빈 DB 마이그레이션 29개와 합성 계정 5개를 사용해 실제 저장을 검증했다.
로그인·프로필, 초안/PDF·투고, 2인 심사·수정·재투고·채택·최종본 확인,
참가 신청·확정·체크인, 납부 저장·문서 3종 발급·인쇄·취소가 모두 통과했다.
문서 동시 발급·권한/무결성·환불/참가 취소·로그아웃 검사까지 9개 그룹 PASS다.

새 환경 초기화를 막던 마이그레이션 두 곳과 로그인 직후 입력을 덮어쓰는 로딩 문제를 수정했다.
재현 가능한 환경 준비·검증 스크립트와 운영자 실행 안내를 추가했다.
타입·프로덕션 빌드·JS/Python/shell 문법·CLI/설정 캐시 회귀·npm audit·diff 검사를 수행했다.

운영 데이터와 운영 DB 마이그레이션은 변경하지 않는다. 실제 OAuth 제공자, 외부 결제/메일은 제외했다.
PR·CI·머지·Vercel 배포 커밋과 배포 후 읽기 전용 전체 페이지 검증은 해당 PR의 Validation에 기록한다.
복구는 PR revert 또는 직전 Vercel 배포를 사용한다. 이번 테스트 컨테이너는 작업 종료 시 개별 중지한다.
