## 검증 결과

- 연결된 Supabase에 `20260926002130_cmt_essential_workflows.sql` 및 `20260926002939_require_submission_authors.sql` 적용. 마이그레이션 상태 일치.
- 롤백 트랜잭션에서 접수 마감 후 제출 거절, 심사 단계 종료 후 의견 입력 거절, 공동저자 이메일과 일치하는 심사위원 배정 거절 확인.
- 최종본은 단계 종료 시 저장 거절, 단계 개방 시 채택 원고 소유자 저장 허용. 최종본 메타데이터와 비공개 저장소 파일은 저자에게 보이고 심사위원에게 보이지 않음을 확인.
- 빈 저자 명단 및 형식에 맞지 않는 저자 이메일의 제출 거절 확인. 검증 후 시험용 사용자·원고·심사 0건.
- `node --check site/submission.js`, `git diff --check`, HTML ID 및 JS 참조 검사 통과. 데스크톱과 390px 모바일 화면 검토.
- Supabase 보안 advisory 0건. 공개 사이트에서 운영 단계·역할별 안내·로그인 화면 로딩 확인.

## 운영 전 남은 설정

운영자가 확정된 일정에 맞춰 단계와 마감을 열어야 한다. 실제 이메일·Google·Naver 로그인은 해당 서비스의 운영용 인증 설정에 따른다. 자동 판정 이메일은 현재 범위에 포함되지 않으며, 결과는 로그인 화면에서 확인한다.
