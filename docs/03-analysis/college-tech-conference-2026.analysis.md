## 확인한 동작

- `node --check site/app.js` 통과.
- 로컬 HTTP 서버에서 첫 화면, 네 개 발표 분야, CFP 및 참가 안내가 표시됨.
- 둘째 날 탭을 누르면 첫째 날 내용이 숨겨지고 금요일 세션이 표시됨.
- 모바일 390px에서 메뉴 열기·닫기가 동작하고 문서 가로폭이 화면폭과 같음.
- 영문 행사개요·CFP 펼침에 자격과 가안 일정이 표시됨.
- 2026-10-30은 금요일, 12월 17–18일은 목·금요일임을 달력 계산으로 확인함.
- 업데이트한 사이트에서 확정 개최일·동부캠퍼스·일반 참가신청 마감과 발표자 별도 등록 안내를 확인함.
- 브라우저 오류 로그가 비어 있음.

## 변경·제약

설계의 접수·심사·등록·체크인·자료집은 별도 기관 승인 도구를 연결하는 구조다. 현재 사이트는 정적 안내 화면이며, 실제 투고·등록 버튼을 활성화하지 않았다. 확정한 행사일·캠퍼스·일반 참가신청 마감과 가안인 논문 일정을 구분한다. 원고나 개인정보를 수집하지 않는다.

## 다음 조치

1. 동부캠퍼스 건물·호실, 주최·주관·예산·연락처를 결정하고 국·영문 공고를 승인한다.
2. 투고·심사 서비스와 등록·회계 도구를 선정하고 실제 URL·권한을 설정한다.
3. 등록번호·원고ID 연결, 기업 공개동의, 체크인·확인서 흐름을 시험한다.
4. 확정된 콘텐츠와 링크를 사이트에 반영한 뒤 모바일·접근성·현장 장애 시나리오를 다시 검수한다.

전체 설계 대조율은 90% 미만이다. 다음 PDCA 단계는 Act이며, 미완료 항목의 상당수는 개최기관의 결정과 승인 후에 구현할 수 있다.
