## 확인한 동작

- `node --check site/app.js` 통과.
- 로컬 HTTP 서버에서 첫 화면, 네 개 발표 분야, CFP 및 참가 안내가 표시됨.
- 둘째 날 탭을 누르면 첫째 날 내용이 숨겨지고 금요일 세션이 표시됨.
- 모바일 390px에서 메뉴 열기·닫기가 동작하고 문서 가로폭이 화면폭과 같음.
- 영문 행사개요·CFP 펼침에 자격과 가안 일정이 표시됨.
- 2026-10-30은 금요일, 12월 17–18일은 목·금요일임을 달력 계산으로 확인함.
- 업데이트한 사이트에서 확정 개최일·동부캠퍼스·일반 참가신청 마감과 발표자 별도 등록 안내를 확인함.
- 브라우저 오류 로그가 비어 있음.
- CFP 전문 페이지가 로컬 브라우저에 표시되고, 1280px 화면에서 가로 넘침과 콘솔 오류가 없음.
- 배포된 `co-rnbd.org/cfp.html`이 HTTPS 200을 반환하고 로컬 `site/cfp.html`과 SHA-256 해시가 일치함(검증 시 DNS를 Vercel IP로 지정).

## 변경·제약

설계의 접수·심사·등록·체크인·자료집은 별도 기관 승인 도구를 연결하는 구조다. 현재 사이트는 정적 안내 화면이며, 실제 투고·등록 버튼을 활성화하지 않았다. 확정한 행사일·캠퍼스·일반 참가신청 마감과 가안인 논문 일정을 구분한다. 원고나 개인정보를 수집하지 않는다. Supabase에는 테이블·정책·스토리지를 만들지 않았으며 Vercel 환경변수는 향후 구현을 위한 연결 설정이다.

## 다음 조치

1. 동부캠퍼스 건물·호실, 주최·주관·예산·연락처를 결정하고 국·영문 공고를 승인한다.
2. 투고·심사 서비스와 등록·회계 도구를 선정하고 실제 URL·권한을 설정한다.
3. 등록번호·원고ID 연결, 기업 공개동의, 체크인·확인서 흐름을 시험한다.
4. 확정된 콘텐츠와 링크를 사이트에 반영한 뒤 모바일·접근성·현장 장애 시나리오를 다시 검수한다.

전체 설계 대조율은 90% 미만이다. 다음 PDCA 단계는 Act이며, 미완료 항목의 상당수는 개최기관의 결정과 승인 후에 구현할 수 있다.

### 후속 일정·기관 로고 수정 검수 (2026-10-13)

이번 후속 요청 6개 항목을 모두 반영했다: 네 일정 +10일, 요일·시간·확정/가안 구분, 국영문 동기화, UC 첨부 로고 교체, 교육부 확대·기관명 크기 조정, 참가신청 운영 설정 동기화.

- 새 일정: 일반 참가신청 2026-12-14 18:00 KST, 원고 접수 2026-12-21 18:00 KST, 채택 통보 2027-01-04, 최종본·발표자 등록 2027-01-11 18:00 KST. 모두 월요일이며, 이전 날짜와 정확히 10일 차이다.
- 행사 2027-01-21–22일과 투고 시작 11월 16일 가안은 유지했다.
- 첨부 UC 로고와 저장한 PNG의 바이트가 일치한다. 교육부 PDF 표시 폭은 85pt에서 118pt로 확대했고, 네 국문 기관명 잉크 높이는 약 10.5pt로 맞췄다.
- A4 1쪽 렌더링·텍스트 경계 검사, 웹 1440px·390px 로고·날짜·가로 넘침·브라우저 예외 검수, 타입 검사·빌드·diff 검사 통과.

- 이전 등록 마감으로 되돌리는 조건부 SQL은 같은 마이그레이션에 주석으로 기록했다. 참가자·원고 데이터는 수정하지 않았다.
- 운영 웹 문안·PDF 일치 확인은 Git PR 병합과 배포 후 수행한다.
