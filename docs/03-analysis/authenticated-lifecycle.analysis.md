## 발견·수정한 제품 문제

1. 빈 DB에 없는 플랫폼 함수 `rls_auto_enable()`의 REVOKE로 마이그레이션이 중단됐다.
   함수 존재 시에만 회수하며, 존재하는 함수의 anon/authenticated 실행 권한 회수가 유지되는지 트랜잭션으로 검증했다.
2. 운영 관리자 계정 선행 검사가 빈 신규 Auth에서 마이그레이션을 막았다.
   완전히 빈 신규 설치만 허용하고 계정이 있는 설치에는 기존 검사를 유지한다. 합성 계정이 있는 DB에서 거부를 확인했다.
3. 로그인 직후 프로필 조회가 끝나기 전에 입력 화면이 열려 빠른 입력이 덮어써졌다.
   초기 프로필·권한·원고/심사 조회 완료 후 화면을 열고 기존 generation 확인으로 오래된 응답의 재표시를 차단했다.
   프로필 요청 시 작업 공간이 숨겨졌는지와 즉시 입력·저장·재조회를 검사했다.

설계의 핵심 흐름을 모두 검증했다. 결과 JSON·스크린샷·합성 PDF는 작업 머신의
`/tmp/co-rnbd-authenticated-20261107c/`에 보관했다. 비공개 `.env.local-status.json`은 공유 대상이 아니다.
기존 운영 DB에 적용된 과거 마이그레이션을 재실행하지 않으며 운영 데이터·권한 변경은 없다.
Google/Naver 실제 OAuth, 외부 결제·메일 발송은 로컬 시험 대상에 포함하지 않는다.
