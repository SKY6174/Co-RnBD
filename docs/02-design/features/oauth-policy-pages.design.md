# OAuth 공개 정책 페이지 설계

## 경로와 탐색
- 개인정보처리방침: `/privacy.html`
- 서비스 이용약관: `/terms.html`
- 정적 HTML로 제공하며 로그인 없이 접근한다.
- 홈페이지, CFP, 투고·심사 화면 푸터에 동일한 경로를 연결한다.

## 개인정보처리방침 내용
- 서비스 범위: 컨퍼런스 사이트 계정과 논문·사례 투고·심사. 참가등록은 별도 절차.
- 실제 처리 항목: Auth 이메일·소셜 식별자, 프로필 이름·소속, 원고 제목·초록·분야·유형·발표 희망, 공동저자 이름·소속·선택 이메일, PDF·파일명, 심사 의견·배정·판정 및 처리 시각.
- Google 로그인: 기본 프로필과 이메일로 인증·계정 연결; Google Drive/Gmail 등 다른 데이터에 접근하지 않음.
- 네이버 로그인: 앱별 사용자 식별자, 이름, 이메일로 인증·계정 연결; 다른 네이버 프로필 항목은 요청하지 않음. 목차와 본문에서 Google·네이버 로그인 내용을 명시하고 각 제공업체의 개인정보처리방침을 연결한다.
- 처리 목적과 접근 범위: 로그인·계정 관리, 원고 접수·심사·결과 안내, 저자·배정 심사위원·위원장에 한정한 자료 접근.
- 제공업체: Supabase Auth/DB/Storage, Vercel 정적 호스팅·함수, Google 및 Naver 로그인(활성화 시). 실제 계약상 위탁·국외 이전 정보는 운영 주체 확인 후 고지한다.
- 개인정보처리자: 울산과학대학교 산학협력단. 문의처: kysong@uc.ac.kr.
- 보유기간: 학회 종료일인 2026년 12월 18일까지. 종료 후 지체 없이 파기하되 법령상 의무가 있으면 해당 범위에서 분리 보관한다.
- 정보주체 권리와 안전성 조치는 현재 시스템에서 실제로 제공할 수 있는 절차와 기술을 기준으로 작성한다.

## 이용약관 내용
- 계정 및 투고 화면의 목적, 사용자 책임, 제출 권한과 제3자 권리, 심사·판정, 계정 제한 및 서비스 변경·중단, 개인정보처리방침 연결.
- 원고의 저작권 귀속 또는 자동 공개를 임의로 정하지 않는다. 공개·자료집 수록은 별도 승인 범위를 따른다.
- 확정되지 않은 접수 일정·등록비·환불 규칙은 포함하지 않는다.

## 검증
- HTML 문서 제목·언어·반응형 뷰포트·링크를 확인한다.
- 로컬 200 응답과 배포 후 `https://co-rnbd.org/privacy.html`, `https://co-rnbd.org/terms.html`의 공개 200 응답을 확인한다.
