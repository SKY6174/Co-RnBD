### 1.1 공식 표기 규칙

포스터·홈페이지 첫 화면에서 `T-VET Co-R&BD Conference 2026`을 대표 제목으로, `제1회 전문대학 산학공동 R&BD 컨퍼런스`를 국문 정식명으로 쓴다. `THE INAUGURAL CO-R&BD CONFERENCE`는 첫 개최를 설명하는 보조 문구로 사용한다. 영문 설명은 `College–Industry Cooperation for Research and Business Development`로 통일한다. 국문 부제는 `전문기술석사 연구와 산학공동기술개발과제의 만남`이다. 2026년 CFP와 세션명에는 `산학공동기술개발과제 성과발표`를 쓴다.

구형 후보명 `PTM–CoR&D`, `Meister Co-R&D`, `K-TECH Connect`는 새 공고·화면·자료집에 사용하지 않는다. 브랜드 약어의 상표·도메인 사용 가능 여부는 별도 확인한다.

## 3. CFP와 심사 설계

### 3.1 제출 규칙

2026-10-13 기관 표기 간격 후속 지시: 주최·주관·후원 표기는 3pt 아래로, 기관 로고는 10pt 위로 이동한다. 웹에서는 각각 4px·13⅓px에 해당하는 간격을 적용한다. 직전의 로고 크기·비율·수평 위치·그림 중심 정렬과 본문은 유지한다. PDF 좌표·텍스트 대조, A4 렌더링, 웹 데스크톱·390px 표시와 배포 파일 일치로 확인한다. 공개 PDF·CSS만 영향이 있으며 이전 커밋으로 복원·재배포할 수 있다.

2026-10-13 최신 로고 편집 지시: 디지텍 로고는 현재 높이의 80%로 축소하고 비율을 유지한다. UC·교육부·한국연구재단의 표시 크기는 유지한다. 하단 기관 로고는 국문 글자 기준 대신 투명 여백을 제외한 그림 전체의 수직 중심을 맞춘다. PDF와 웹 CFP에 같은 기준을 적용하며, 기존 디지텍 배치 칸의 수평 중심도 유지한다. 검수는 수정 전·후 PDF 로고 치수(디지텍 0.8배, 나머지 동일), 로고의 수직 중심, A4 렌더링, 데스크톱·390px 웹 표시와 배포된 PDF 일치 확인으로 한다.

2026-10-13 최신 일정 지시: 일반 참가신청 마감은 **2027-01-05(화) 18:00 KST**, 최종본·발표자 등록 마감 가안은 **2027-01-12(화) 18:00 KST**로 수정한다. 두 날짜가 아래 이전 편집 기록보다 우선한다. 웹·PDF·국영문 문안·운영 명세를 맞추고, 운영 DB의 2026 회차 등록 마감 한 행을 같은 시각으로 옮긴다. 조건부 데이터 마이그레이션과 이전 시각 복원 SQL을 기록한다. 원고 접수 12월 21일, 채택 통보 1월 4일, 행사 1월 21–22일은 그대로 사용한다. 최종본 날짜는 계속 가안이며 DB의 논문 단계 마감 null 값과 단계 스위치는 유지한다.

2026-10-13 후속 편집 지시: 화면에 표시된 네 일정을 정확히 10일씩 연기한다. 일반 참가신청 마감은 2026-12-14(월) 18:00 KST(확정), 원고 접수는 2026-12-21(월) 18:00 KST(가안), 채택 통보는 2027-01-04(월)(가안), 최종본·발표자 등록은 2027-01-11(월) 18:00 KST(가안)이다. 행사 2027-01-21–22일과 투고 시작 가안 11월 16일은 유지한다. 국영문 문안·PDF·첫 화면·운영 명세를 맞춘다. 참가신청 운영 DB의 2026 회차 등록 마감도 같은 시각으로 옮기되 접수 개시 여부와 가안인 논문 단계의 null 마감은 유지한다. 기존 12월 4일 마감과 일치하는 2026 회차 설정 한 행만 수정하고, 복구 시 이전 시각을 조건부로 되돌린다.

울산과학대학교 로고는 사용자가 두 번째 첨부로 제공한 UC 심볼·국영문 시그니처로 교체한다. 교육부 로고를 확대하고, 네 기관의 국문 이름 글자 높이가 비슷하도록 PDF와 웹 로고별 표시 크기를 조정한다. 로고 자체 비율·색상은 유지한다. 검수는 새 날짜·요일·시각, A4 로고 크기·여백, 웹 390px·데스크톱 표시, 등록 설정 한 행과 공개 설정 응답을 확인한다.

2026-10-13 CFP 편집 지시: 네 번째 메인 트랙은 `T-VET 정책·교육연구`이며 교육과정 운영과 산학협력 사례를 포함한다. A4 한 장 CFP는 상단 오른쪽에 T-VET Co-R&BD 로고, 아래쪽에 주최·주관·후원 기관 로고를 배치한다. 트랙만 01–04로 표시하고 제출 유형은 문장형 설명 대신 글머리표와 명사구로 통일한다. 본문 행간과 단락 사이 여백을 확보한다. PDF의 기업 기밀·자료집 공개 승인 안내 문단과 중복 제출 전 확인 상자는 사용자 삭제 지시에 따라 제외한다. 기존 비공개 원고 접근·공개 동의 운영 규칙은 계속 적용한다.

### 3.0 발표자료 검토 반영 (2026-10-13)

홈페이지 소개 문장을 읽기 쉽게 나누고, 세 가지 행사 목표와 네 모집 분야의 설명을 발표자료의 상세 문안으로 통일한다. 투고·심사 화면의 모집 분야 표기는 같은 이름을 사용하되 DB의 분야 코드와 기존 원고 값은 바꾸지 않는다. 프로그램 시간은 고정폭 숫자로 정렬한다. 포스터 설치는 확정 전 일정에서 제외하고 전시 필요 여부 및 사전 제출·설치 방법을 추후 안내한다. 발표 장소는 세부 공간이 정해지지 않았으므로 세션 옆에 `장소 추후 안내`로 표시한다.

후속 사용자 결정: 일반 참가신청 마감을 **2027-01-05(화) 18:00 KST**로 변경하고 접수를 연다. 2026 회차의 현재 DB 마감이 2026-12-14 18:00 KST이고 접수가 닫혀 있을 때만 새 마감과 `registration_open = true`를 함께 적용한다. 논문 접수·심사·최종본 단계의 상태와 가안 마감은 바꾸지 않는다. 기존 참가 신청, 프로필, 프로그램 데이터는 수정하지 않는다. 롤백은 해당 설정 행만 이전 값으로 되돌리는 조건부 SQL로 한다.

웹 CFP와 국·영문 원문도 네 번째 트랙과 기관 표기를 맞춘다. 수정 PDF는 `/downloads/t-vet-co-rbd-2026-call-for-papers-and-cases.pdf`로 공개하고 웹 CFP에 내려받기 링크를 둔다. 이번 변경은 공개 문안과 파일만 다루며 인증·DB·투고 처리에는 영향이 없다. 이전 커밋으로 되돌려 재배포할 수 있다. 검수는 A4 렌더링, 텍스트 대조, 웹 데스크톱·390px 레이아웃, 타입 검사·빌드와 운영 URL의 PDF 일치 확인으로 한다.

응용연구는 2–4쪽 확장초록, 산학공동기술개발·교육운영 사례는 2쪽, 진행연구 포스터·데모는 1쪽 요약을 PDF로 받는다. 국문 또는 영문 원고를 허용한다. 저자 중 1명 이상은 전문대학 소속이거나 해당 전문대학 공동과제 참여자여야 한다. 저자는 희망 발표형태를 제시할 수 있고, 최종 형태는 프로그램위원회가 결정한다.

기업 기밀은 원고에서 제외한다. 심사용 원고, 등록자 배포본, 웹 공개본의 범위를 원고마다 별도로 기록한다. 기업 공동저자 또는 공개 권한자가 웹 공개 범위를 승인하기 전에는 원문을 게시하지 않는다.

### 3.2 심사와 판정

원고마다 심사위원 2명을 배정한다. 동일 기관·동일 과제 관계자는 심사에서 제외한다. 연구는 방법·검증·현장 활용성을, 사례는 성과 근거·적용 가능성을 중심으로 평가하며, 교육운영 사례에는 해당 교육성과 기준을 적용한다. 점수, 의견, 이해관계 확인, 수정요청, 최종 판정은 원고ID에 연결한다. 접수 권장량을 기관별 채택 할당량으로 사용하지 않는다.

## 4. 안내·접수 시스템 설계

### 4.1 서비스 구성

첫해는 대학 CMS의 공개 페이지, 기관 승인 투고·심사 서비스, 기관 승인 등록 도구, QR 체크인, 접근 제한된 운영대장을 연결한다. 투고와 참가등록은 서로 다른 절차임을 첫 화면에서 명확히 표시한다. 독자 앱이나 통합 시스템 구축 여부는 첫해 실제 운영 데이터를 본 뒤 결정한다.

| 영역 | 필수 화면·기능 | 운영 원칙 |
|---|---|---|
| 공개 홈페이지 | 행사소개, CFP, 프로그램·연사, 등록, 숙박·교통, 공지·문의 | 모바일 우선, 국문 중심·영문 행사개요 |
| 투고·심사 | 제출, 수정, 파일 버전, 배정, 평가, 판정, 저자 통지 | 원고ID 기준; 심사위원은 배정 원고만 열람 |
| 참가등록 | 2027년 1월 5일 일반 신청 마감, 채택 후 발표자 별도 등록 | 회원 계정 기준; 발표자는 별도 절차 |
| 체크인 | QR 또는 등록번호 검색, 오프라인 백업 | QR에는 임의 코드만 저장 |
| 자료집·확인서 | 승인된 원고 공개, 참석·발표 확인 | 실제 체크인과 발표 완료를 구분 |
| 과제 매칭 | 기업 수요 등록, 상담 예약, 상담 결과, 후속 일정 | 공개 가능한 수요 요약과 비공개 연락처 분리 |

심사 서비스는 CMT 개설 가능 여부를 먼저 확인하고, 일정상 확정이 어렵다면 다른 승인 서비스로 전환한다. 제품명, 가격, 승인조건은 도입 시점의 공식 문서를 다시 확인한다. URL은 기관이 발급한 실제 주소만 공고에 넣는다.

### 4.1.1 공개 사이트 배포와 Supabase 연결 결정 (2026-09-26)

사용자 지정 GitHub 저장소 `SKY6174/Co-RnBD`의 `main`을 공개 CFP의 소스 저장소로 사용한다. Vercel의 기존 `co-rnbd` 프로젝트는 이 저장소와 연결하고, 저장소의 `site/`를 정적 사이트 루트로 설정한다. 첫 배포는 원고·개인정보 입력 기능이 없는 검토용 시안을 그대로 제공한다. `co-rnbd.org`는 해당 Vercel 프로젝트에 연결했고, Vercel 도메인 검증을 통과했다.

Supabase는 사용자가 `Co-RnBD` 조직 아래에 만든 `Co-RnBD-2026` 프로젝트에 이 로컬 작업 폴더를 연결한다. 현재 공개 사이트는 데이터 저장·인증 기능이 없으므로 API 키를 브라우저 코드에 넣거나 참가·투고 테이블을 임의로 만들지 않는다. 등록·투고 기능은 별도 개인정보·권한·보존기간 설계와 승인 후 구현한다.

### 4.2 정보 구조와 연결 키

| 정보 단위 | 최소 항목 | 연결·상태 |
|---|---|---|
| 원고 | 원고ID, 유형·분야, 제목, 저자·소속, 파일 버전, 공개 범위 | 제출→심사→판정→최종본→발표 |
| 심사 | 원고ID, 심사위원ID, 이해관계, 평가·의견, 제출일 | 배정→완료→판정 반영 |
| 참가자 | 등록번호, 이름·소속·이메일, 참가일, 발표 여부, 숙박·식사·셔틀 선택 | 신청→확정→체크인 |
| 발표 | 원고ID, 등록번호, 형태, 세션·시간·장소, 발표 확인 | 편성→현장 발표→확인서 |
| 결제·정산 | 등록번호 또는 기관ID, 청구액, 납부·환불 상태, 영수증 | 회계 담당만 접근 |
| 기업 수요·상담 | 수요ID, 공개 요약, 담당자, 상담ID, 참가기관, 후속회의 | 접수→매칭→상담→후속조치 |

외부 서비스 간 자동 연동이 없으면 제한된 운영대장과 정기 CSV 대조를 사용한다. 원고ID·등록번호·수요ID는 서로 다른 값으로 유지한다. 수집 항목과 보존기간은 개최기관의 개인정보 처리 기준에 맞춰 공고 전에 확정한다. 심사위원에게 숙박·납부 정보가, 현장 체크인 담당에게 원고 심사의견이 노출되지 않게 권한을 분리한다.

### 4.3 첫 화면과 사용 흐름

행사 심볼은 `site/favicon.png`에 두고 모든 공개 HTML 페이지에서 브라우저 탭 아이콘으로 사용한다.

첫 화면 상단에는 영문 대표명·국문 정식명·부제를 위 순서로 놓고, 개최일·동부캠퍼스·일반 참가신청 마감은 `확정`, 논문 일정·세부 공간은 `가안` 또는 `추후 안내`로 표시한다. 주요 행동은 `논문·사례 제출`, `일반 참가신청`, `프로그램 보기` 세 가지다. 두 신청의 완료 여부를 각각 확인할 수 있어야 한다. 주요 메뉴는 행사소개 / 프로그램·연사 / 논문·사례 모집 / 참가등록 / 숙박·교통 / 자료집 / 공지·문의다.

운영자는 게시 전 제목과 링크, 일정의 확정 여부를 확인한다. 마감 이후에도 이미 등록한 사용자가 자신의 접수·등록 상태와 변경 공지를 볼 수 있도록 한다. 장애가 나면 사무국 연락처와 대체 접수·확인 절차를 공지한다.

## 5. 구현·검수 순서

1. 조직위원회가 행사 조건과 브랜드 표기를 승인한다.
2. 대학 전산·개인정보·회계 담당이 서비스·권한·수집항목·결제방식을 확정한다.
3. 홈페이지와 CFP를 만들고 사무국이 국·영문 표기, 일정, 제출 규칙을 대조한다.
4. 투고·심사와 참가등록을 설정하고 원고ID·등록번호 대조 절차를 시험한다.
5. 숙박·식사·셔틀, 정산, QR 체크인, 현장 백업명단을 시험한다.
6. 실제 제출·수정·심사·채택통보·최종본·발표자 등록·자료집 공개까지 예시 원고로 점검한다.
7. 행사 전 리허설에서 발표 장비, 인터넷 장애, QR 중복, 발표자 교체, 변경 공지를 확인한다.

검수 완료 기준은 테스트 원고가 접수부터 승인 자료집까지 추적되고, 일반 참가자는 원고ID 없이 등록되며, 심사·회계·숙박 권한이 분리되고, 오프라인 체크인과 실제 참석·발표 확인이 가능한 것이다.

## 6. 공고 전 미결정 사항

- 동부캠퍼스의 건물·호실·대관 세부사항, 수업·시험 조율, 호텔·만찬장·셔틀 동선
- 공동주최·주관 기관, 로고, 조직위원장·프로그램위원장·사무국
- 등록비·숙박비 부담, 후원 조건, 실제 업체 견적과 환불 규정
- 공식 웹·투고·등록 URL과 사무국 이메일, 개인정보 안내 및 보존기간
- 기업 기술수요와 자료집·사진·영상 공개 동의 양식
- 키노트 섭외 및 대학별 참가·발표 수요
