# Co-R&BD Conference 2026 — 참가신청 운영 명세

> 내부 실행 초안 · 2026-09-26 · [상세설계](../docs/02-design/features/college-tech-conference-2026.design.md) 기준

## 1. 확정 정보와 신청 경로

| 항목 | 기준 |
|---|---|
| 행사 | 2026년 12월 17일(목)–18일(금), 울산과학대학교 동부캠퍼스 |
| 일반 참가신청 마감 | **2026년 10월 30일(금) 18:00 KST** |
| 발표자 | 11월 채택 통보 후 **별도 등록**; 최종본·발표자 등록 11월 27일은 현재 가안 |
| 신청 시작·URL | 미정; 기관 승인 도구 설정 후 공지 |
| 건물·호실, 등록비, 숙박·셔틀 | 미정; 신청 화면 공개 전 운영 조건 확정 |

일반 참가자와 발표자의 신청 링크·화면을 구분한다. 일반 참가자는 원고ID 없이 신청한다. 발표자는 원고 채택 이후 원고ID와 발표자 등록번호를 연결한다. 한 사람이 일반 신청 후 발표자로 채택되면 중복 등록·이중 청구가 발생하지 않도록 사무국이 전환 절차를 제공한다.

## 2. 일반 참가신청 화면

| 묶음 | 최소 입력 항목 | 처리 기준 |
|---|---|---|
| 신청자 | 이름, 소속기관, 직책 또는 참여 역할, 이메일 | 등록 확인과 행사 안내에 사용 |
| 참가 | 참석일(양일/목/금), 식사 필요 여부, 숙박 필요 여부, 셔틀 필요 여부 | 실제 계약 가능한 선택지만 노출 |
| 기관 신청 | 기관별 일괄 신청 여부, 기관 담당자 | 일괄 신청은 참가자별 이름·이메일을 구분 |
| 안내 확인 | 참가비·취소기준·개인정보 안내 확인 | 확정된 문안과 버전을 보존 |

전화번호, 장애·식이 관련 세부정보, 객실 동실 선호 등은 운영상 필요성과 처리 책임이 확인된 경우에만 추가한다. 민감한 요청사항은 일반 메모 필드에 자유롭게 받지 않는다.

### 화면에 표시할 문구

> **일반 참가신청 마감: 2026년 10월 30일(금) 18:00 KST**<br>
> 행사: 2026년 12월 17일(목)–18일(금), 울산과학대학교 동부캠퍼스<br>
> 논문·사례 발표자는 채택 통보 후 별도 절차로 등록합니다.<br>
> 신청 URL, 참가비, 숙박·셔틀 조건은 확정 후 공지합니다.

마감시각은 서버 또는 기관 승인 도구의 시간대 설정을 **Asia/Seoul**로 확인한다. 마감 이후에는 새 일반 신청을 닫고, 이미 접수된 신청의 변경·취소는 공지된 절차로 처리한다. 화면에는 현재 상태(접수 전/접수 중/마감)를 표시한다.

## 3. 채택 발표자 등록 화면

채택 통보 메일의 전용 경로에서 원고ID, 발표자 이름·소속·이메일, 발표형태, 참석일, 숙박·식사·셔틀 수요를 확인한다. 원고ID는 채택된 원고만 연결하고, 공동저자 중 현장 발표자 1명 이상이 등록돼야 `발표 준비 완료`로 표시한다. 발표자 등록 마감은 프로그램위원회가 논문 일정과 함께 확정한다.

일반 신청을 먼저 한 발표자는 기존 등록번호를 재사용하거나 사무국에서 명확히 연결한다. 참가비 정책이 정해지기 전에는 등록 화면에서 금액을 청구하지 않는다.

## 4. 운영대장 상태와 확인 메일

| 경로 | 상태 | 발송·확인 정보 |
|---|---|---|
| 일반 참가자 | 신청 전 → 접수 → 확인 → 변경/취소 → 체크인 | 접수번호, 신청 내용, 변경·취소 방법, 세부 장소 추후 안내 |
| 발표자 | 채택 → 등록 초대 → 등록 → 최종본 확인 → 발표 편성 → 체크인·발표 확인 | 원고ID, 등록번호, 최종본·발표 일정, 현장 안내 |

접수번호와 원고ID는 개인정보 자체를 포함하지 않는 임의 값으로 발급한다. 확인 메일에는 비밀 심사의견, 타인의 신청정보, 불필요한 내부 운영메모를 넣지 않는다. 중복 이메일이 있어도 자동으로 다른 참가자 정보를 합치지 않는다.

### 일반 참가신청 확인 문안

> 제목: [Co-R&BD Conference 2026] 일반 참가신청 접수 확인<br>
> {이름}님, 신청이 접수되었습니다. 접수번호: {등록번호}.<br>
> 행사: 2026년 12월 17일(목)–18일(금), 울산과학대학교 동부캠퍼스.<br>
> 신청 내역: {참석일/식사/숙박/셔틀 선택}. 세부 장소와 참가 안내는 확정 후 발송합니다.<br>
> 변경·취소: {승인된 절차·문의처}.

이 문안은 실제 메일 발송 전 주최기관·문의처·개인정보 문구와 함께 승인받는다.

## 5. 운영자 권한과 검수

- 일반 신청 담당자는 참가·숙박·셔틀 수요만 관리하고 심사의견을 볼 수 없게 한다.
- 학술 담당자는 발표자와 원고ID 연결을 확인하되 결제 세부내역 접근은 회계 담당으로 제한한다.
- 등록자 명단 내보내기, 보존기간, 삭제·백업은 개최기관의 개인정보 처리 기준에 맞춘다.
- 시험 신청으로 접수 확인, 마감시각, 수정·취소, 중복 신청, 일반→발표자 전환, 기관별 일괄 신청, 오프라인 체크인을 점검한다.
- 실제 운영 URL을 사이트와 CFP에 넣기 전, 일반 참가자 경로와 발표자 경로를 각각 끝까지 실행해 확인한다.

## 6. 공개 전 필요한 결정

1. 일반 참가신청을 받을 기관 승인 도구와 운영 URL, 신청 시작일.
2. 등록비·숙박비 부담방식, 환불·취소 기준, 호텔·셔틀 제공 범위.
3. 동부캠퍼스 건물·호실 및 현장 이동 동선.
4. 주최·주관, 공식 문의처, 개인정보 처리 문안·보존기간.
5. 채택 발표자 등록 마감과 일반 신청자에서 발표자로 전환하는 회계 처리.
